# Models and checkpoints

All three models are trained by the official PhysicsNeMo unified external-aerodynamics recipe
(`src/train.py`, unmodified) and saved as PhysicsNeMo `.mdlus` checkpoints.

| Model | Implementation | Recipe config | Parameters |
|---|---|---|---|
| GeoTransolver | `physicsnemo.models.geotransolver.GeoTransolver` | [`ev_geotransolver.yaml`](../configs/recipe/model/ev_geotransolver.yaml) | 9.05 M |
| SMART | `physicsnemo.experimental.models.smart.SMART` | [`ev_smart_noses.yaml`](../configs/recipe/model/ev_smart_noses.yaml), [`ev_smart_lengths.yaml`](../configs/recipe/model/ev_smart_lengths.yaml) | 29.45 M |
| AB-UPT | `physicsnemo.experimental.models.ab_upt.ABUPT` | [`ev_ab_upt.yaml`](../configs/recipe/model/ev_ab_upt.yaml) | 6.01 M |

The configs are the official surface configs plus the adaptations in
[report §5.2](report.md#52-对官方配置的改动全部) (generated by `train_aero.data.make_folds`).

## Training setup

300 epochs, StepLR (×0.1 at epoch 150), float32, no compilation, batch size 1, 32 000
supervised points per step, per-cell loss (`measure_weighted=false`), no augmentation, each
model's official optimizer, learning rate and loss. The final checkpoint is used; nothing is
selected on the test set.

## Checkpoints

Final checkpoints are published as assets of the GitHub release, one file per run:

```
<family>-<model>-<fold>-<run>.mdlus      e.g. noses-gt-n2-seed0.mdlus
```

[`results/checkpoints.json`](../results/checkpoints.json) lists every asset with its run and
SHA-256. The run's full recipe config is in `results/runs/<family>/<model>/<fold>/<run>/`
(`resolved_config.yaml` for training, `bench_infer_config.yaml` for inference).

Load one with the recipe config of its run:

```python
import hydra
from omegaconf import OmegaConf
from physicsnemo.utils import load_checkpoint

cfg = OmegaConf.load("results/runs/noses/gt/n2/seed0/bench_infer_config.yaml")
model = hydra.utils.instantiate(cfg.model, _convert_="partial")
load_checkpoint(path="checkpoints/", models=model, device="cuda")   # folder holding the .mdlus
```

`load_checkpoint` looks for `<ModelClass>.0.300.mdlus`, so rename the downloaded asset accordingly
(`GeoTransolver`, `SMART` or `ABUPT`; the class is in the manifest's `model_class`).
Inputs must go through the same recipe dataset pipeline; the benchmark wrapper
`train_aero.benchmark.plugin.RecipeSurfaceWrapper` shows the full inference path.

## Intended use and limits

Research baselines for surface Cp / Cf prediction on this train family. They are trained on
13–23 cases each and are not validated outside the geometry ranges and yaw angles of
[docs/data.md](data.md).
